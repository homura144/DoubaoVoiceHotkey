# DoubaoVoiceHotkey v0.1.0-alpha.1

首个可下载的 Alpha（早期预发布）版本。面向 Windows 10/11 x64，非官方豆包输入法快捷键工具。

**兼容性尚未完成实机验证：** 本版本未验证具体 Windows 版本与豆包输入法版本的组合。GitHub Actions 构建成功只说明编译和打包完成，不代表麦克风、快捷键、文字提交或句尾防漏字已经通过实机测试。项目依赖豆包输入法未公开的本地 RPC（进程间调用）接口，豆包升级后可能失效。

## 本版内容

- 默认 F8 开始/停止语音输入，Esc 取消；支持按住说话和鼠标侧键。
- 包含此前已提交的句尾保护：停止后先保留 200 ms 尾部录音，再发送停止请求；随后保持 400 ms 的 Finalizing（等待最终提交）状态，期间不启动新会话。
- 提供被动自检与会使用麦克风的实时自检。
- 原提交 `d99a0ea4` 的 [Windows 构建](https://github.com/homura144/DoubaoVoiceHotkey/actions/runs/37523750900) 已成功，产物为 `DoubaoVoiceHotkey-win-x64`。本 Release 由标签工作流重新构建；防漏字逻辑没有重新实现。

## 安装与运行

1. 安装并启用 Windows 版豆包输入法，确认它自身的语音输入可用。
2. 从本页 Assets（下载附件）下载 `DoubaoVoiceHotkey.exe`，保存到固定文件夹。它自带 .NET 运行时，无需另装 .NET。
3. 若旧版正在运行，先从托盘退出旧版，再运行新文件。程序会驻留系统托盘。
4. 打开记事本，点击输入区域，按 F8 开始说话，再按 F8 停止并提交文字。

首次运行创建的配置位于 `%APPDATA%\DoubaoVoiceHotkey\settings.json`。升级时已有配置会继续使用；测试前请核对 `StopGraceMs=200`、`PostStopSettleMs=400`。修改后在托盘菜单选择 **Reload settings（重新加载配置）**。

## 最简句尾测试

1. 在记事本中按 F8 开始，等语音界面出现后说：“今天测试快速停止，最后三个字是苹果树。”
2. 说完“树”立即按 F8 停止，不提前停顿；等待文字最终落定后再开始下一轮。重复 10 次，记录末尾“苹果树”是否完整。
3. 用同一句话做 10 次对照：说完后等 1 秒再按 F8。记录两组漏字次数；这是短时自测，不能证明所有场景都不会漏字。
4. 另试一次停止后立即再按 F8：Finalizing 期间应不开始新会话；待处理完成后再按 F8，应能正常开始。

如果仍漏字，可把 `StopGraceMs` 改为 `300` 后重新加载配置并重复测试。请保留 Windows 版本（运行 `winver` 查看）、豆包输入法版本、配置值及两组漏字次数。

托盘菜单 **Run self-check（运行自检）** 不主动录音；**Run live RPC self-check（运行实时接口自检）** 会短暂使用麦克风。自检成功也不能代替上述完整文字检查。

日志：`%LOCALAPPDATA%\DoubaoVoiceHotkey\app.log`  
自检结果：`%LOCALAPPDATA%\DoubaoVoiceHotkey\probe-result.txt`
